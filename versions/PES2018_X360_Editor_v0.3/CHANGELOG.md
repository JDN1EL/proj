# Histórico de versões

## v0.3 — compatibilidade e dados de equipe
- Removida a exigência rígida de exatamente 510 equipes/elencos; contagens lidas do cabeçalho até o limite físico PES 2018.
- Relacionamento equipe/elenco/tática pelo ID.
- Janela maximizada e layout mais adaptável ao espaço de trabalho do Windows.
- Ordenação numérica de camisas e IDs, alfabética para nomes.
- Seleção/edição de jogadores que estejam apenas no banco global.
- Pré-visualização de 3 planos x 3 formações e cópia de configuração de outra equipe.
- Cópia opcional de elenco + táticas como modelo.
- Recuperação com opção “Carregar mesmo assim” e modo somente leitura para arquivos estruturalmente inconsistentes.
- Testes com arquivos reais contendo 508 e 510 equipes.

## v0.2
- Edição de equipes, elencos, camisas, dados básicos, atributos e habilidades.
- Salvamento em cópia separada, backup do destino e validação pós-gravação.
